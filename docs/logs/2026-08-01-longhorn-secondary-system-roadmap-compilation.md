# Longhorn Secondary-System Roadmap Compilation

Date: 2026-08-01
Status: complete

## Decision

Keep the current g05 generation and compile the useful remaining Longhorn
mechanisms into roadmaps 009 through 018. Settings is the first product-facing
lane, but it starts only after exact consumer admission, retained-adapter
decomposition, and reusable conformance fixtures.

## Sequence

1. consumer admission and adapter decomposition
2. Settings registry and sparse shell
3. provider, credential-reference, and product settings
4. command catalogue, keymaps, and palette
5. cross-panel operations
6. retained notifications
7. backup, restore, and recovery
8. local backend-bridge alignment
9. conditional remote transport and secondary-window transfer
10. conformance closeout and explicit deferrals

The sequence uses cards 027 through 055. Card 027 is the sole ready card.
Production remote transport is paused at card 050 pending a Nucleus remote host
pairing/session contract. Secondary-window work is paused at card 051 pending
an operator-selected workflow. Neither gate blocks closeout of the implemented
local adoption set.

## Boundaries

Longhorn owns reusable registry, session, resolution, ledger, operation,
backup, bridge, and transfer mechanics. Nucleus owns product schemas, durable
domain state, authority, wording, redaction, command effects, credential
references, and UI policy.

Hosted Surfaces, generic product history, isolated/backing native content,
native OS notifications, and offline command queues are not adopted. Current
Nucleus Browser islands remain the only concrete native-content exception.

## Source Caveat

Longhorn had an unrelated active dirty worktree during planning. This compile
changed no Longhorn files and grants no authority to consume dirty source-tree
state. Card 027 must record one exact clean source and produced-artifact graph
before implementation begins.

## Structural Baseline

Nucleus Doctor already reports oversized-file debt, including retained
migration adapters. Roadmap 009 addresses the migration-edge decomposition;
it does not absorb unrelated repository-wide structural debt. Later closeout
must show that Doctor is no worse than the admitted baseline.
