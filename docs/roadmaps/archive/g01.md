## Intent And Boundary

Bootstrap Nucleus: the Northstar/Effigy planning spine, the Rust workspace,
the first domain contracts, server and control proof surfaces, local state,
command evidence, runtime readiness diagnostics, and the engine-first
host-authority correction.

The 2026-06-17 reassessment closed g01 as foundation history and moved active
planning to g02, because the next work needed an orchestration and engine
boundary decision before runtime implementation could continue.

## Shipped Outcomes

- Planning and repo spine: Northstar docs authority, Effigy task routing,
  working-rules contract, Rust workspace with small testable crates.
- First domain contracts: project identity, task records, harness adapters
  and registry, server boundary, storage persistence, native harness runtime,
  engine host authority.
- Server runtime proofs: local state implementation, control API and runtime
  sequencing, local request handling, transport readiness, module
  decomposition and IPC readiness.
- Read-only desktop proofs: serialization and shell bootstrap, control
  diagnostics and panel foundation, project state records and read-only
  switcher, task records with read-only list, detail, mutation boundary,
  transition controls, and authoring semantics.
- Command and host proofs: `nucleusd` local runtime, command runner execution
  readiness, command evidence persistence and query, local process supervision,
  sandbox and process-control backends, first read-only spawn through server
  integration, constrained command input, history query shape, and
  diagnostics client read model plus panel hardening.
- Engine-first correction: host-authority map vocabulary, execution safety
  and artifact policy, spawn readiness gates, and runtime capability
  discovery — clients never become state authorities.

- No compatibility shims were granted; pre-1.0 breaking changes stay
  operator-approved per the working rules.

  server-side from the start.
- Retained risk at closeout: runtime implementation had not yet begun, which
  is why the reassessment rolled planning to g02 instead of extending
  foundation proofs.
