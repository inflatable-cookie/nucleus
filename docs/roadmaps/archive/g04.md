## Intent And Boundary

Turn the g01–g03 server proofs into one coherent product workflow: select a
project, inspect tasks and planning context, delegate bounded work, watch
evidence, review results, and see the next step — without clients becoming
state authorities and without widening memory, provider, SCM, panel, or
final UI implementation.

## Shipped Outcomes

- Product workflow slice: rebaseline and vertical-slice selection, server
  workflow summary and read model, `nucleusd` and Effigy inspection for the
  summary, and a disposable desktop proof surface with no final UI
  commitments.
- Selected-task work loop: drilldown and handoff readiness, composition,
  action readiness, operator action gate, command admission controls, outcome
  coherence, review and next-step presentation, SCM handoff readiness,
  review decision controls and outcome routing, route admission, completion
  and rework paths.
- Product shell: UI architecture refocus, workspace hosting extraction,
  project rail, shell skeleton, design checkpoint, workspace grid, host-routed
  terminal panel, memory panel, resource foundation, control workflow,
  multi-resource attachment and targeting, transient chat and promotion,
  shared project files control.
- Agent chat and editor slice: initial Agent Chat vertical slice with task
  context and workflow runs, code editor slice, task-attributed diff review,
  review-guided rework, floating composer, window geometry persistence, and
  panel simplification.
- Swallowtail adoption: Agent Chat adoption and task-execution adoption
  closed the secondary-system application loop.
- Audit hardening band (tasks `042`–`048`): execution-safety honesty and
  enforcement, CI and validation runway, persistence correctness hardening,
  admission vocabulary consolidation, engine boundary migration, desktop
  contract integrity, and roadmap residue archival.
