Prompt notes never read as requirements: proof files, the run context and the
recorded build-output cleanup are optional unless the brief names them.

- Proof files are described as optional delivery for proof the brief names. A
  brief that names no visual or rendered proof gets a paragraph saying there is
  nothing to deliver, and the size limits read as packaging ("summarise larger
  evidence into compact evidence plus hashes") instead of a reason to stop.
- The build-output cleanup note says only that earlier build outputs may be gone
  and to re-run a command whose output it relies on. It names no history lookup.
- The extended context index says to read a section if needed and that a failed
  or refused optional read is never a blocker; nothing in the run context is owed
  for the turn unless the brief or a review finding names it.
