- A project message no longer waits on a T3Code thread the operator settled by hand. A settled thread is treated like an archived one: it is not a candidate, and a send refused because the thread is settled clears the routing cache and moves to the next live thread, or tells the sender to handle the message itself. Nucleus still never unsettles a thread to deliver, and a refusal now names its route (project message, task role, agent message or reply) instead of "Reviewer continuation".
