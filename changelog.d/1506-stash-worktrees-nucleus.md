- Local task-workspace placement is now separated from the pinned work volume (`workRoot` / `workVolumeId`) via `localWorkspaceRoot` (`NUCLEUS_LOCAL_WORKSPACE_ROOT`) and optional `retainedWorkspaceRoots` (`NUCLEUS_RETAINED_WORKSPACE_ROOTS`). Opting in directs new Nucleus-owned local task workspaces (such as `<workRoot>/worktrees/nucleus`) inside the verified work volume while positively bound workspaces on `<workRoot>/queue/workspaces` continue and clean up in place; installs that do not opt in preserve existing placement.
