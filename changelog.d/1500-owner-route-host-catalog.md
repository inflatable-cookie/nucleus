Owner profile controls (`route` and `set_routing`) now read the profile catalogs their own decision reads instead of the legacy primary host's snapshot alone. A T3-owned (or BB-owned) task whose legacy primary is offline or was never read stays routable while its own host answers for profiles; an unread catalog still waits, and the refusal now names the host it needs. Reviewer and coordinator routes stay on the task's bound host, and the preview (`next`) and the control read the same per-host evidence.
