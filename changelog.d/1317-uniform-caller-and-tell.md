Caller resolution is one order for every host and thread kind: an explicit ticket, the current run's ticket from the verified thread (even when the shell environment is stale), then the host-verified identity. A slow host answers "The host is slow; retry". An explicit ticket is the asker and delivery target for every verb that records a caller (`decision.add`, `lead.submit`, `question.answer`, `tell`); Nucleus records the ticket's thread, never an MCP session or host scope from the environment. A named ticket whose file is missing refuses when the host identity is an MCP session, rather than recording that session. Any recognised caller can tell a project planner or task role, including a task-planner ticket, a retained thread and a plain host thread. An omitted host defaults to the sole online host of the kind. A QA settlement notice whose host is unavailable stays queued and is redelivered when the host answers; a typed unknown delivery is never resent. A decision answer is delivered to the recorded asker or queued with a visible wait (attempts > 0); an identity Nucleus cannot route is shown on the decision. A tell to a mid-turn Paseo agent still waits for idle (papercut e629a20c, deprecated).
