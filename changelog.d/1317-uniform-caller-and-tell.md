Caller resolution is one order for every host and thread kind: an explicit ticket, the current run's ticket from the verified thread (even when the shell environment is stale), then the host-verified identity. A slow host answers "The host is slow; retry". Any recognised caller can tell a project planner or task role, including a task-planner ticket, a retained thread and a plain host thread. An omitted host defaults to the sole online host of the kind. A QA settlement notice whose host is unavailable stays queued and is redelivered when the host answers; a typed unknown delivery is never resent. A tell to a mid-turn Paseo agent still waits for idle (papercut e629a20c, deprecated).
