Provider options shared across hosts now have one canonical key. Speed is one control in Settings → Profiles. Paseo spells it `service_tier` for Codex and `fast_mode` for Claude, and T3Code spells it `serviceTier` and `fastMode`. Each host's table translates it at launch. Stored host spellings move to the canonical key once, and any value no table maps is listed and left as stored. A profile at the default speed sends nothing and runs on every host. A speed a host can't express makes the profile unavailable on that host, with a note on the profile, so the launch is never refused at send. Single-host options (Paseo's Codex plan mode, T3's Codex cyber access and Claude ultracode) get canonical keys too, so their defaults no longer block the other host.
