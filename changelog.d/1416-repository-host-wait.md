A repository whose host kind is set now waits for that host before its first worker dispatch. While the host is offline, reconnecting, or has no readable catalog, the task stays queued with the named wait `Waiting for repository host <label>` and takes no workspace, profile charge or slot, instead of starting on another host's profile. Healthy projects keep dispatching, and the task dispatches once its host returns. A kind with no registered host shows a configuration wait.
