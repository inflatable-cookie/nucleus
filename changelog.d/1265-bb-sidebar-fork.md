Spec 062's BB adapter now owns BB's sidebar instead of accepting the built-in one:
the plugin vendor-copies BB's thread list at a pinned release commit, keeps a four-seam
patch set with a recorded rebase routine and a drift check, and keeps the MIT notice in
`THIRD_PARTY_NOTICES.md`. A Nucleus task's worktree group starts collapsed and its header
row carries the task number and title, its state, its PR number and what it is waiting on,
from one batched read; other groups behave exactly as upstream. The global board sits in
BB's left rail with an attention badge, and a per-project board renders in a fixed thread
tab plus a deep-linkable route from the sidebar's project rows.

The plan gains a sidebar phase (5), the board phase (6) now covers both boards, and the
trial moves to phase 7. Phases 0–4 are unchanged.
