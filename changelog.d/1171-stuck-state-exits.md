Stuck tasks now reach someone with a working exit: a worker waiting on its own long job is no longer read as a missing callback, a recovery episode that never starts a run escalates to the planner ladder after a bound, a question whose native delivery goes unknown is answerable by the planner, a reviewer swap records which eligibility condition failed, and a superseded run's clean pushed head is adopted so `next` offers `move to=review` instead of looping `restart`.
