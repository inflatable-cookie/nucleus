### Changed

- On the Rust engine's board, moving a repository into a project from Settings → Projects reassigns it in the engine. The project editor shows the resolved planner and each repository's base branch, required checks and hung-tool limit instead of controls the Rust engine retires.
- Settings → Profiles on the Rust board can add, duplicate and edit profiles, including provider, model and thinking. Refresh shows the latest catalog held by the engine. Usage strips reflect recorded worker and reviewer assignments.
