Run process cleanup never stops a process a live non-init ancestor still owns, so a retained agent host, its MCP or report helper and a retained thread's tools stay running and keep their scratch. A process stopped for a run and respawned under the same run within ten minutes is recorded once and left alone instead of being chased. One sweep takes one process-table snapshot and one ownership read for every run it settles, a cleanup that completed is not scanned again, and the sweep runs on its own host lane, one host-scoped sweep that covers every task's owed cleanup, instead of holding a task's lane. An owner control now starts as soon as its task's lane resumes, ahead of any observation quanta queued behind a wedge.
