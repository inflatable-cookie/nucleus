Starting T3Code now starts the Nucleus daemon when none is running. Once `nucleus t3 install` has registered the provider, T3's own cold-start probe runs the `nucleus-acp` launcher, which starts one detached daemon for the local T3 connection. Repeated and concurrent starts converge on one daemon, a service roll blocks the start until it settles, and the daemon's ten-minute grace after the last host closes decides when it exits, as before.
