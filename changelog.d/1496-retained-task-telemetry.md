- Telemetry now keeps a rolling 90-day aggregate history. When a finished task's detailed history is purged after 4 days, Nucleus first writes one compact measurement record for it in the same transaction, so 7d, 30d and 90d ranges report real counts, percentiles and partial denominators instead of only the last few days. The records hold no titles, briefs, messages, logs or run, thread and workspace identities. A capture failure keeps the task's history and shows in retention health.
- The Telemetry screen offers 24h, 7d, 30d and 90d and retires All. Each result says whether the window is complete, labels it partial where history was purged before retention began, and notes that task controls cover only 30 days. The `queue.telemetry` RPC still accepts `all`, bounded by what is retained.
