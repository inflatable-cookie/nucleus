A merge that meets a replaced or retired native participant now owns it. A
retired worker's record names the worker ticket a replacement displaced, and
that ticket keeps the run root its own identity names beside the task's recorded
leaf, so the ordinary owned-tool proof scans the participant's real scratch,
proves quiescence and lets the merge continue instead of refusing with "a
participant run temporary directory is unrecorded".

When the grace window and the host-process reap cannot settle that proof, the
merge wait is recorded as an `operator_needed` stop whose exit is
`retry_effect`, rather than a `lifecycle` wait that never clears. The recorded
stop now keys its own attention notice, so a notice an earlier transient wait
superseded cannot hide the block that followed it, and a transient wait
supersedes its notice with the reason instead of an empty error.
