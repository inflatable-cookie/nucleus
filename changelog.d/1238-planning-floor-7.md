Durable operations record their pre-send receipt from one typed proof: a refusal that may prove nothing was sent is decided once, with the parked restart's own evidence hashes and the shared unchanged-attempt facts, instead of two long conjunctions inside the settle path. An operation's lane key now reads its payload through the shared schemas rather than casting it.

The repository re-key describes each re-keyed family once — how its rows are read, which record names the source, which record already claims a target path and how a matched row moves — so the plan, the occupancy checks and the apply read every family's stored shape once instead of three times. A stored record the step cannot decode now refuses the step with a named code and an explanation rather than being skipped while the receipt reports success.

The owner-to-planner migration reads one typed liveness state: a qualified owner is observed on its own host and an unqualified legacy thread only on a Paseo host, so a host that cannot hold the thread, a missing host read and an ambiguous seeded id are unknown and never retire the owner record.

Lane documents come from the task's typed lane-document declaration alone. The inference from brief prose and `## Read` headings is gone, and a declaration the lane list no longer offers is reported instead of pinned.
