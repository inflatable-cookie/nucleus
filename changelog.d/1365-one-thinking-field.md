Profiles keep one canonical Thinking level and one Mode. The profile editor
always shows one Thinking and one Mode control, and no host's thinking option
(T3's Pi `thinking`, its `reasoningEffort` or older `reasoning` select) appears
again as a feature field. On open, stored profiles that held their thinking in a
host option or a host spelling move to the canonical level. Values no host table
maps stay as stored and are reported. The task card shows the canonical level a
task launches with, not the host's spelling.
