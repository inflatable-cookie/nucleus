A released slot wait no longer becomes an `operator_needed` stop that reads "No stop or wait; the task is progressing", and so no longer spends a recovery launch. A stored stop of that kind settles once nothing owns it, so a released published verdict applies on the ordinary pass. A role's old failed run no longer keeps a waiting task's T3 row visible: the row shows a role's fault only while the task's own attention owns it, and a current question or permission still shows the row.
