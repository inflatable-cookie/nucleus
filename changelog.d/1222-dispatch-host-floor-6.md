The dispatch and host modules rate 7 or more on the code-rating charter after this change. The prompt
module is now one owner per mechanism — the shared rules and context blocks, the run's scope and report
callback, the role dispatch, and one module per role's prompt — so a role's text is no longer one
if-chain over two dozen blocks. The participant lease reads one settled-thread predicate and typed host
refusals instead of matching host and reason text, and the withdrawn native-question settlement is its
own owner. Run reservation is split into the source facts, the run intent, the admission transaction
and the composition over them. The host adapter contract composes its capability groups rather than
declaring about seventy-five optional members in one list, and the answered-question read is typed: a
host that cannot read the transcript reports an unknown read, which Nucleus records once, instead of an
empty answer list the resume path read as "the operator answered nothing".
