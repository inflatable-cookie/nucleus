A reviewer run whose thread the host archived is released by observation instead of fencing every launch. Nucleus uses the same per-agent archive proof the ordinary archive path accepts, records the terminal observation, clears the retained reviewer binding and never selects that run for relaunch again. A `restart`, `route` or `move` whose launch is fenced names the run that fences it and what releases it, in the reply and in `next`, rather than returning success with no run created.
