Explicit commands and force accept any confirmed responsible planner of the
task's project, not only the one thread project messages route to. A planner
that dispatched or owns project tasks, the registered planner and named agents
all qualify, so a project's own planner is no longer refused because another
planner thread is the current pick. An incomplete shortlist still accepts the
routing pick and the registered planner. A planner whose shortlist read was
discarded mid-read, for example by its own call, is checked against the last
read that finished within 10 minutes instead of being refused. Refusals now
name their reason: an incomplete read and its unread hosts, an unconfirmed
read, or a caller that is not a responsible planner for the project.
